## Service APIs

Each service has documentation and `env.example` defaults. Ports below are summarized; `docs/system-reference.md` is canonical.

- **SUI Service** (Port 3001) - Blockchain operations
- **DGraph Service** (Port 3003) - Social data queries
- **Walrus Service** (Port 3002) - Storage & premium content
- **Dgraph Service** (Port 3003) - Markets & governance
- **MCP Service** (Port 3009) - AI assistant integration (read-only tools)
- **ZK Service** (Port 3010) - Cryptographic proofs
- **Webhook Service** (Port 3011) - GitHub webhook deploys
- **Sandbox Service** (Port 3007) - dApp execution
